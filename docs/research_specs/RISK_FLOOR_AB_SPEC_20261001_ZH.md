# 實驗規格：CG1AT 的 POSTFLIP_RISK_FLOOR 開關對照（預登記，尚未執行）

狀態：**草案，待用戶授權後由本機（有 worker 連線的環境）執行。** 本檔不是派送，沒有啟動任何 job、沒有 live 變更。

## 1. 假說與重疊檢查
- **假說：** 在 CG1AT（V58＋CG1 凍結＋被動掛最佳買價）上，`V12G_POSTFLIP_RISK_FLOOR=ON` 相對 `OFF`，會（H1）把平均成本壓低、（H2）改善尾部，並（H3）在已觀察反轉的路徑上使配對平均損益不劣於 OFF。
- **來源：** 217 場 CG1AT 路徑中，132 條反轉過，114 條（86%）在反轉後超過 50% 的下單請求被地板擋掉（`tools/risk_floor_lock_stats.py`）。玩具模擬（`tools/toy_floor_sim2.py`，校準到這 217 場，被動逆選擇 adv≈0.025 與 217 場實測的 −1.6 分一致）預測：成本約減半、最差 5% 改善約 +190、反轉路徑配對平均差約 +20（2 SE 約 ±8）。
- **與既有工作的關係：** V41（`v12g_postflip_risk_floor_20260927_v41`）曾在 PADD80 底座、固定十場上比較過地板，結論是壓低尾虧但平均仍負。本實驗的差異：底座是 CG1AT（含被動最佳買價、CG1 凍結、STOP290）、場次是 fresh-100a 的反轉路徑、且事先寫判準。執行前仍需由執行者再核對 `RESEARCH_CURRENT.md` 與近鄰報告是否已有等價測試（我只讀了摘要，未讀 V41 全文）。

## 2. 設計：配對 A/B，只改一個變數
| 臂 | 內容 |
|---|---|
| ON（參照） | **重用既有 CG1AT 結果**（fresh-100a job `btc5m-cg1at-fresh100a-20260930`，arm=CG1AT），不重跑 |
| OFF（新） | 同一場、同一 base/模型/env，唯一差異 `V12G_POSTFLIP_RISK_FLOOR=OFF`（其餘 env 逐字相同，見 `protocol/CG1AT_fresh100a_PROTOCOL.json`） |

- 地板在第一次 FLIP 之前不啟用，所以 OFF 與 ON 在第一次 FLIP 的畫面（含）之前的計畫、回報必須逐筆相同。**這是必過的 parity 檢查**，不過則該路徑作廢並回報，不替補。
- OFF 路徑不得改動任何凍結套件；用新的後續套件（命名建議 `btc5m_floor_ab_<date>_v1`）。
- 引擎沿用 V49 hftbacktest native，250/250ms，risk queue，零手續費；`capital_cap=null`。

## 3. 場次（事先固定，不看結果、不看標籤）
- 規則：fresh-100a 的 CG1AT 路徑中，**執行期有 ≥1 次 FLIP 且 FLIP 後有 ≥1 筆風險地板決策**者，依 market_id 升冪。這是 runtime 可觀察事件，不是結算或績效。
- 清單：`docs/research_specs/RISK_FLOOR_AB_MARKETS_20261001.json`（共 68 場：階段 1＝前 10、階段 2＝接著 30、階段 3＝其餘 28）。

- 無模型種子維度（V49 線 theta 固定），故不適用「雙 seed」。

## 4. 階段（先小後大）
1. **階段 1：10 場 OFF。** 目標是驗證 parity、機制與審計能通過，不下經濟結論。時間：依交接記錄「29 路 10.58 分鐘（4 執行緒）」粗估，10 路在分鐘量級，**未實測**。
2. **階段 2：再 30 場（累計 40）。** 階段 1 全部通過 parity 與審計才進行。
3. **階段 3：其餘 28 場（累計 68，即 fresh-100a 全部反轉路徑）。** 用於確認；結果不得回頭改判準。

## 5. 指標（離線評分；結算標籤只在回放完成後使用）
主指標（反轉路徑，逐場配對 d = pnl_ON − pnl_OFF，pnl 為最終勝方分支損益）：
- **P1：** d 的平均與 95% 區間（以場為單位 bootstrap）。
- **P2：** 平均成本比 cost_ON / cost_OFF。
- **P3：** 尾部＝各臂最差 5 場平均（階段 2 以 40 場、最差 5 場；階段 1 只描述不判定）。
輔助（必須全部報告，不得只報成功例）：假反轉／真反轉分開的配對差（分組用離線標籤，僅作診斷）、改善與退步場數、最差場、反轉後 NEW 單數與被擋比例、峰值資金、owner/pending 是否全部終局。

## 6. 預登記判準（執行前凍結）
以階段 2（40 場）為判定點，階段 3 為確認：
- **支持地板：** P1 區間下界 > 0，**或**（P1 平均 > 0 且 P3 ON 優於 OFF 且 P2 < 0.8）。
- **否定地板：** P1 區間上界 < 0，或 P3 ON 劣於 OFF 且 P1 平均 < 0。
- **其餘：** 不確定，報告區間，不改設計重跑同一批。
- **對玩具模擬的檢驗：** 若 P1 平均為負且區間不含 0，或 P2 > 0.9，則玩具模擬在被動／主動動態上不成立，需先重新校準再用它排序後續設計。
這些判準不是新的實盤門檻，也不構成晉級或 live 資格；任何結論仍是已消費、零費用、BTC5M 的研究診斷。
