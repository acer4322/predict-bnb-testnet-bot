# 現貨波動切換策略（候選，參數凍結；2026-10-02）

## 規則（凍結，不再調整）
- 特徵：市場視窗開始前 5 分鐘 BTCUSDT 現貨 1 秒對數報酬的標準差 `rv_5m`（資料：data-api.binance.vision 1 秒 K 線，tools/fetch_spot_1s.py）。
- 門檻（取自探索期 id 2648950–2768404 的分位數）：q.50 = 3.1834e-05；q.67 = 3.9759e-05（每秒報酬標準差）。
- 若 `rv_5m` ≥ 門檻 → 「買冷門」：熱門中價 ≥ .75 時，每 2 秒買非熱門那邊 15 股，上限 300 股，290 秒停止，吃單。
- 否則 → FAV：價格帶 .55–.70，每 2 秒買 15 股熱門，上限 300 股，熱門中價 ≤ .40 即凍結，吃單。
- 不收手續費（另需做 1%、2% 敏感度）。
