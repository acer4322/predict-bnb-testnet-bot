# BTC5M 畢業研究總結（2026-10-02，雲端 session）

## 結論
在可取得的資料（519 場重播＋最新 215 場事件檔的引擎驗證＋Target 匯出＋現貨 1 秒＋Polymarket 成交）上，沒有找到能穩定通過獨立樣本、且滿足使用者「逐一版」標準（三類市場中只有一類虧損、其餘兩類為正且虧損絕對值小於兩者較小者；整體期望為正）的機制。

## 關鍵規律
1. 熱門的勝率在 id 區塊間輪替（熱門中價 ≥ .70 的實際勝率 90%→61%，買價約 81–87%），沒有固定的價位或時間優勢；35 個價位×時間格子沒有一格在兩半同時為正。
2. 真反轉與假反轉在翻轉當下及翻轉前無法區分（盤口、現貨、歷史翻轉率、Polymarket、成交流向的 AUC 約 0.5–0.65；翻轉後 5–20 秒的價格 AUC 0.56–0.65）。任何翻轉應對只在兩類之間搬風險；公平價格的保險、降價、窄價帶、賣出、對沖都改變不了真反轉虧損對假反轉收益約 1.3–1.4 倍的比例。
3. 結構上唯一能通過逐一版的是「做空波動（FAV）＋做多波動（買冷門／Target 式雙邊平衡）」的組合；Target 在 105 場的混合是通過的，但我們沒有可行的做多波動腿：自己的雙邊被動配對在引擎中顯著為負，Target 新年代被動價值約 0（−0.17 分）。
4. 切換策略（5 分鐘現貨波動）在 519 場探索與滾動驗證通過（合併整體 +14.6～+16.6），對手續費與延遲穩健；但在 15 場與之後 100 場獨立樣本上未通過（整體 −10.7～−3.3），波動指標的 AUC 在新樣本只有 0.513／0.479，沒有複現。
5. 模擬器：引擎已在 Linux 重現（6/6 golden 全部相同）；被動單 +5 秒價值在引擎約 −1.2～−3.0 分，與 Target 真實成交的差距主要由資料時間（Target 成交時間是成交時間，掛單時間為推斷）造成，不能歸因於引擎。
6. 市場對現貨與流向訊息定價有效：現貨公平價（Brier 0.1501）輸給市場中價（0.1326，t=270 秒）；Polymarket 價格不領先；Predict 成交流向、現貨主動買賣量順勢買都虧；Polymarket 結算規則為 TWAP，與 Predict（結束價對起點價）不同（結果一致率 78%）。

- 等比例縮小（clip 與 cap 一起縮）邏輯完全不變；只縮上限或受最小下單量限制時，買入會集中在視窗前段（前 60 秒占比 34% → 52–54%）、買價變貴、更常觸及上限，真反轉單位虧損變大（−19.6 → −32），與原版每場損益的相關降到 0.88–0.97。
- 歷史真實吃單最小約 9.5 股（clip 1.5 的 ×0.1 不一定可行）；若場地最小單約 10 股，改用市場抽樣（full clip/cap，只交易預先決定的子集，如 id 取模）可以保持每場邏輯完全相同。
