## Continuity and evidence

- Before a new experiment, search the current handoff, nearby reports/artifacts and tools for semantic overlap. Record the distinct hypothesis and what prior result it extends. On resumption, inspect the known job and collected artifacts before creating any replacement. Do not repeat completed rounds.
- Keep protocol, source/model/data hashes, parent checkpoint and optimizer continuity, cohorts, execution semantics and outcome tied to the same run. Preserve frozen originals; create a separate successor for an actual new experiment. Update the small current pointer only after verifying the successor's state.
- Separate microworld diagnostics, component tests, native execution, economic results and deployment evidence. A process exit or audit PASS does not imply model promotion, positive economics or live readiness. Performance-grade/official forward claims require the applicable realistic HFT + execution-tape contract; optimistic microworld results remain diagnostics.
- Target is an offline observation source, not an oracle for private intent. The current SAFE teacher is a local evaluator, not the Target account. Final-direction experiments must be labelled oracle diagnostics and excluded from autonomous/live capability claims.
- Preserve sealed/fresh/official holdouts. Freeze candidates before held-out evaluation; if results inform later design, mark the cohort consumed. Report both seeds and paired market-level improvements AND regressions, tails and both settlement branches; do not select only a successful example or pooled average.
- Inspect metadata, selected columns and bounded market slices first. Do not dump whole databases, large tapes, or files over 50 MB into context. Local orchestration and small diagnostics are allowed; heavy training/HFT/replay belongs on the verified second PC through [worker.md](worker.md).
- For a large read-only search or reconciliation, the main agent defines the exact market/artifact scope, duplicate-work boundary, fields to verify, evidence links or hashes, output table, and `UNKNOWN` handling before assigning the bounded check to GPT-6 Luna at `xhigh` reasoning. The main agent retains experiment design, interpretation of conflicting evidence, complex code, and final decisions; independently spot-checks consequential claims. Agent delegation does not authorize worker dispatch, live changes, or altering frozen artifacts.
